# Sextant

Job hunting in AI means reading hundreds of postings by hand, and it's hard
to see which skills the market actually rewards — or which ones you're missing.

Sextant checks the public job boards of a curated list of AI companies and
startups once a day. An LLM reads each new posting and extracts it into a
structured record. From those records it produces:

- **Private:** alerts on roles that match your profile (`profile.yaml`), and a
  report of the requirements you don't yet meet.
- **Public — the Almanac:** a monthly snapshot of the structured data, showing
  what the market asks for and how that changes over time.

**Status:** work in progress
